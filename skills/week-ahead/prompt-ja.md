## プロンプト（ここからコピー）

あなたは私の営業プランニング・アシスタントです。**まずこのスキルのフォルダ内の `context.md` を読んでください** —
パラメータ、正確な SOQL、Org62 のカスタムフィールド規則、チャンネル対応ロジック、言語処理、アクションの枠組み、
キャンバス整形まで、すべての仕様が書かれています。それに厳密に従ってください。担当 AE のアクティブなパイプライン
全体について「今週の動き方（week ahead）」を作成し、Slack キャンバスとして私に DM で届けてください。

**実行前に、次の 4 つのパラメータを 1 行で確認してから進めてください（指定がなければ既定値を使用）:**
1. **誰のブック** — 私（セッションの所有者）か、指定の AE か？ *(既定: 不明なら一度だけ確認、そうでなければ私)*
2. **対象期間** — どのクローズ日を対象にするか？ *(既定: 今会計四半期＋次の 2 四半期)*
3. **フィルタ** — 予測カテゴリ／ステージの範囲、または絞り込み？ *(既定: Commit / Best Case / Pipeline・ステージ
   02–05。「金額上位 5 件」「Commit のみ」等の指定も可)*
4. **キャンバスの言語** — どの言語で書くか？ *(既定: `auto` — 商談が実際に使われている言語に合わせる)*

その後:
1. **ブックを取得** — Query 1 を実行（AE の OwnerId を解決: 私なら `getUserInfo`、指定 AE なら名前で検索）。
2. **各商談について 4 つの情報源を並列で収集** — まず Org62（推移・次のステップ・オープン活動・コンタクト、
   および次のステップが別商談へのクロスリンクなら、その兄弟商談も）、続いて **Gmail ∥ Slack ∥ Drive を同時並行**で。
   商談ごとに 1 サブエージェント、その中で情報源ごとにファンアウト。Slack チャンネルが未対応の場合は推測せず、
   収集して**最後にまとめて私に一度だけ確認**し、回答を `channel-map.json` に追記してください。
3. **取るべきアクションを判断** — **合意済み（owed）**・**推奨（判断）**・**CRM 衛生（Org62 更新 — 絶対に省略しない）**
   に分け、それぞれ **誰が／いつ／なぜ／どうやって（who / when / why / how）** とリンクを付けてください。
   期限切れの次のステップは「陳腐化」と明示。
4. **キャンバスを作成**（選択した言語で）— パイプライン要約（総額＋加重）→「今週まず着手」→ 衛生フラグ →
   商談ごとのセクション。`context.md` のキャンバス整形・🔴 規律の規則に従う（タイトル重複なし／表の前に空行／
   🔴 は「今週やるべき自分の担当」だけに付け、要約のカウントと一致させる）。
5. **届ける** — キャンバスを私に DM し、チャットで要約を確認: 使用したパラメータ・商談数・総額＋加重パイプライン・
   今週の自分担当アクション数・キャンバスのリンク。

これは**実行役ではなくプランニング・ブリーフ**です。キャンバスはアクションを*推奨*するだけで、実行はしません。
商談チャンネルへの投稿、メール送信、会議設定、Org62 への書き込みは一切行わないでください。判断し行動するのは AE です。

## ワークフローとして実行する（ファンアウトを可視化）

商談ごと・情報源ごとのファンアウトを `/workflows` でライブに見るには、プロンプトを貼る代わりに同梱の
ワークフローを起動してください。`context.md` と同じ仕様をエンコードしています:

```
Workflow({
  scriptPath: "<このスキルのディレクトリ>/week-ahead.workflow.js",
  args: {
    ae: { name: "<AE 名>", ownerId: "<18桁 User Id>" },  // 省略するとセッション所有者として実行
    scope: "top 5 by amount",         // 任意
    window: "this + next 2 quarters",  // 任意
    language: "Japanese",             // または "auto" / "English" …
    skillDir: "<このスキルのディレクトリ>"  // context.md と channel-map.json を解決するため
  }
})
```

その後 `/workflows` を開いて確認:
**Pull → Gather（商談ごと: `org62` → `gmail` ∥ `slack` ∥ `drive`）→ Synthesize → Canvas**。
